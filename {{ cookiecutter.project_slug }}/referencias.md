## Como Adicionar Referências

As referências bibliográficas devem ser adicionadas no arquivo `references.bib` usando o formato BibTeX.

Para citar uma referência no texto, use: `{cite}chave_da_referencia`

### Exemplo de Entrada BibTeX

```bibtex
@article{exemplo2023,
  author  = {Silva, João and Santos, Maria},
  title   = {Título do Artigo Científico},
  journal = {Revista Brasileira de Pesquisa},
  year    = {2023},
  volume  = {15},
  number  = {3},
  pages   = {123--145},
  doi     = {10.1234/exemplo.2023}
}
```
