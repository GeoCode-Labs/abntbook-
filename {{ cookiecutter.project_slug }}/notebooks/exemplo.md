# Notebooks Jupyter

Esta seção contém notebooks Jupyter interativos que complementam a documentação.

## Por que usar Notebooks?

Os notebooks Jupyter permitem:

- Combinar código executável com documentação
- Visualizar resultados em tempo real
- Experimentar com diferentes parâmetros
- Criar visualizações interativas

## Notebooks Disponíveis

Explore os notebooks nas subseções ao lado para ver exemplos práticos de análise de dados e implementações.

```{note}
Todos os notebooks podem ser executados diretamente no seu ambiente local ou em plataformas como Google Colab.
```
